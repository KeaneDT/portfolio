# Self-hosted fonts

Fetched 2026-11-10 from the official Google Fonts CSS API using its Latin subset, then saved locally as variable WOFF2 files.

The two WOFF2 files total 93,128 bytes (90.95 KiB), below the 100 KB font budget. They contain the Latin subsets returned by the Google Fonts API; other scripts fall through to the system font stack.
